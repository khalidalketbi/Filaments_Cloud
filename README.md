# Filament Cloud

Cloud filament spool tracker connected to the FSO Supabase project.

## Features
- Email/password authentication
- Add, edit and delete spools
- Track remaining filament in grams
- Track brand, material, color and empty spool weight
- Log filament usage
- Per-user data isolation with Supabase RLS

## Deployment
This is a static site. Deploy the repository directly with Vercel, Netlify, Cloudflare Pages, or GitHub Pages.
